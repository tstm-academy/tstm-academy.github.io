# TSTM Music Academy Portal

Welcome to the official repository for **TSTM Music Academy** based in Tinsukia, Assam. 

This repository hosts our static GitHub Pages site used to distribute RSL (Rockschool) Grade Exam video scripts, mandatory presentation rules, and music performance tutorials to our academy students.
